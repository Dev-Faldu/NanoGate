# Limitations

Stated plainly so that nothing is over-claimed.

## Hardware / environment
- **Power interruptions on the event device.** The ZGX Nano powered off abruptly five times on 2026-09-23 while GPU work was
  running (journal ends mid-stream, no thermal/kernel/OOM events). Development continued with the GPU idle; model-dependent
  benchmarks were run only after power delivery was stable. See RESULTS.md for which runs exist.
- **No root / no Docker socket** on the event device: everything is user-space. `docker-compose.yml` is provided but was not
  executed on this device.
- **Egress control is application-layer.** Remote calls must pass the `EgressGuard`, and sensitive requests never mint a
  ticket, but there is no OS firewall rule. "Remote bytes: 0" means the instrumented connector sent nothing, not that the
  OS prevented all traffic.
- **Offline verification** uses a process-level socket/DNS guard when the host is online (unprivileged user namespaces are
  blocked by AppArmor). The report states which mode ran; for an OS-level test, unplug the network and run `make offline-test`.
- **Power** is GPU-only (NVML). Whole-system power is not readable by unprivileged software; per-request energy is the GPU
  energy delta over the request window and is shared between concurrent requests.

## AI components
- **Router** is trained on public benchmark tasks with automatic rubrics; enterprise free-form answers are out of
  distribution. Discrimination on the partial run was weak (see AI_EVALUATION); results are reported as measured.
- **Streaming cannot escalate**: once tokens are sent, the router scores post-hoc (`ROUTER_POST_HOC_STREAM`).
- **Cache verifier**: 97.4% hard-negative rejection on the authored test split — not 100%. A known miss is a jurisdiction
  qualifier ("…in the EU?"). The authored set was written by the same team as the slot rules (disclosed); PAWS shows a
  40.9% false-accept rate for the verifier on adversarial word-swap pairs — much better than cosine, far from perfect.
- **DLP** is regex + checksum + NER. It will miss novel secret formats and sensitive facts without identifiers. Benchmark
  data was generated by the same team (regression benchmark only). Presidio uses the small spaCy model.
- **No claim of perfect privacy, zero hallucination, or guaranteed savings.**

## Product scope
- Single node, SQLite; no HA, no multi-device federation.
- Receipts are tamper-evident relative to the device's HMAC key; the key is on the same device (no external anchoring).
- `REMOTE_MODE=live` was implemented but not exercised against a paid provider (no credentials were used). `mock` mode is
  labelled "Simulated larger tier" and is served by the local 14B model.
- Scenario FinOps projections depend entirely on `config/scenario.yaml` assumptions (the hardware price there is an assumption).
