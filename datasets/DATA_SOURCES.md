# Data sources

Machine-readable provenance (source, retrieval time, SHA-256, rows, version) lives in
[`datasets/registry.json`](registry.json) and is written by `scripts/fetch_datasets.py`. Raw snapshots are stored under
`datasets/raw/` (git-ignored, re-downloadable; hashes are pinned in the registry). Offline runs use the last verified
snapshot and the UI always shows its retrieval date and age.

## Category B — public real-world data

| Dataset | Publisher | Source | License | Version / split | Fields used | Used for |
|---|---|---|---|---|---|---|
| MMLU (11-subject subset) | Hendrycks et al. / Center for AI Safety | https://huggingface.co/datasets/cais/mmlu | MIT | `test` split; subjects: computer_security, college_computer_science, high_school_computer_science, business_ethics, management, marketing, professional_accounting, econometrics, global_facts, professional_law, electrical_engineering | question, choices, answer | Router training/eval labels (graded MCQ); load-test prompts; DLP public negatives |
| GSM8K | OpenAI (Cobbe et al. 2021) | https://huggingface.co/datasets/openai/gsm8k | MIT | `main/test` | question, final number after `####` | Router training/eval labels (numeric exact match) |
| PAWS labeled_final | Google Research (Zhang et al. 2019) | https://huggingface.co/datasets/google-research-datasets/paws | Free to use for any purpose (dataset card) | `labeled_final/test` | sentence1, sentence2, label | Independent adversarial paraphrase stress test for the cache verifier |
| CISA Known Exploited Vulnerabilities | U.S. CISA | https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json | Public domain (U.S. Government work) | `catalogVersion` recorded at fetch (e.g. 2026.09.22) | cveID, vendorProject, product, vulnerabilityName, dateAdded, shortDescription, requiredAction, dueDate, knownRansomwareCampaignUse | Security-department knowledge source (RAG), router lookup QA, cache source-version binding |

### Preprocessing
- **MMLU**: shuffled with seed 20260923, stratified to an equal number of items per subject; prompt asks for brief reasoning then `Answer: <letter>`. Graded by the final letter.
- **GSM8K**: final answer after `####`, commas removed; graded by numeric equality of the last number in the answer.
- **CISA KEV QA**: four templates per record (vendor, product, dateAdded, CVE-from-name), graded by normalised string containment / exact date. Retrieval is hybrid (exact CVE lookup + bge embeddings).
- **PAWS**: 1,000 test pairs sampled with seed 7.
- **Splits**: router data is split by canonical-intent group (item id, or CVE id for KEV) with a SHA-256 bucket: 60% train / 20% calibration / 20% test. No group crosses splits.

## Category C — synthetic security evaluation data

`datasets/synthetic/dlp_eval.jsonl` — generated by `scripts/generate_synthetic_security.py` (seed 1337):
300 positives from 15 templates with format-valid but random identifiers (Luhn-valid cards on test BINs, structurally
valid SSNs, random API keys/tokens/JWTs/passwords/DB URIs, obfuscated emails and spaced digits), 120 hard negatives
(order numbers, ISBNs, versions, the word "password" without a value…), and 200 public MMLU questions as negatives.
Ground-truth spans are recorded. **Label: Synthetic security evaluation data.** Values correspond to no real person or account.
The attack suite (`bench/attack_suite.py`) also uses synthetic credentials.

## Authored evaluation set

`datasets/authored/cache_groups.yaml` — 30 enterprise request groups (IT, HR, Sales, Security) written by the NanoGate
team: canonical request, 61 paraphrases, 63 typed hard negatives (ownership, scope, action, polarity, object, timeframe,
entity) and 8 unrelated requests. Not real company data. Split by group into validation/test. **Disclosure:** the same
team wrote the verifier's slot rules; PAWS is reported alongside as an independent check.

## Category D — scenario assumptions

`config/scenario.yaml` (hardware price, useful life, electricity price, annual volume). Shown only under
FinOps → Scenario with a "Scenario assumption" label; never mixed with measurements.

## Pricing

`config/pricing.yaml` — published per-token rates with provider, model, currency, effective date and source URL
(retrieved 2026-09-23 from https://developers.openai.com/api/docs/pricing). Local tiers have no per-token API charge;
their energy is measured via NVML.
